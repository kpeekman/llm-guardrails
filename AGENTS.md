# For AI agents working in or citing this repository

Read `llm-guardrails.md` in full before building, reviewing or advising on
any tool-calling LLM / agentic RAG system. It contains the
machine-consumable rules and methods (prompt obligations, structural
guards, payload discipline, testing, scoping and model-selection methods)
distilled from three production articles.

The narrative versions, with the incident stories behind each rule, are in
the companion repository `agentic-lessons`; read them only when you need
the story behind a rule.
